# TMK Portfolio — نسخه دوم (FA / EN / AR)

نسخه بازطراحی‌شده بر مبنای رزومه ارسالی و اصلاحات مالک سایت.

## شروع کار

- فایل `index.html` نسخه فارسی است.
- فایل `demo-en.html` نسخه انگلیسی است.
- فایل `demo-ar.html` نسخه عربی است.
- هر سه نسخه از فایل‌های مشترک `site.css` و `site.js` استفاده می‌کنند.
- برای مشاهده محلی، این پوشه را در یک هاست استاتیک یا سرور HTTP قرار دهید. برای نمونه:
  `python -m http.server 8000`
- پس از انتشار، تغییر لینک زبان‌ها به مسیرهای مستقل `/fa/`, `/en/`, `/ar/` و درج hreflang/canonical متناسب با آدرس نهایی توصیه می‌شود. مسیرهای فعلی برای اجرای مستقیم نسخه ZIP انتخاب شده‌اند.

## افزودن عکس‌های واقعی پروژه‌ها

هر سه HTML دارای یک تگ `<script id="site-config" type="application/json">` در انتهای صفحه هستند.

در همان JSON، فیلد `projectDetails` برای هر پروژه وجود دارد. مثال:

```json
"amandys": {
  "intro": "...",
  "roles": ["..."],
  "website": "https://example.com",
  "gallery": [
    {"src": "assets/gallery/projects/amandys-home.webp", "alt": "صفحه اصلی فروشگاه آماندیس"},
    {"src": "assets/gallery/projects/amandys-search-console.webp", "alt": "گزارش سرچ کنسول پروژه"}
  ],
  "before": {"src": "assets/gallery/projects/amandys-before.webp", "alt": "گزارش قبل از بهینه‌سازی"},
  "after": {"src": "assets/gallery/projects/amandys-after.webp", "alt": "گزارش بعد از بهینه‌سازی"}
}
```

**توجه:** نمونه بالا صرفاً ساختار داده است. آدرس نمونه (`example.com`) را جایگزین نشانی واقعی کنید. هیچ نتیجه، اسکرین‌شات یا عددی در نسخه کنونی ساخته یا جعل نشده است.

فایل‌های تصاویر را داخل پوشه `assets/gallery/projects/` کپی کنید. در نسخه‌های انگلیسی و عربی، `intro`، `roles` و `alt` را به زبان مربوطه ویرایش کنید. اگر وب‌سایتی آدرس رسمی ثبت‌شده نداشته باشد، دکمه «مشاهده وب‌سایت» غیرفعال و با برچسب «لینک سایت پس از ثبت آدرس» نشان داده می‌شود.

برای بخش بهینه‌سازی سرعت، مقایسه تصاویر معتبر PageSpeed Insights یا Lighthouse با تاریخ و شرایط آزمون یکسان توصیه می‌شود. بدون داده قابل استناد، عدد و امتیاز نمایش داده نمی‌شود.

## افزودن تصاویر، فایل و لینک افزونه‌ها

در داده‌های `pluginDetails`، برای هر افزونه می‌توانید این فیلدها را تکمیل کنید:

```json
"gallery": [
  {"src": "assets/gallery/plugins/order-tracking-01.webp", "alt": "تصویر محیط افزونه"}
],
"downloadUrl": "assets/downloads/order-tracking.zip",
"moreUrl": "plugins/order-tracking/index.html"
```

- تا زمانی که `downloadUrl` خالی باشد، دکمه دانلود غیرفعال می‌ماند.
- دکمه «مشاهده بیشتر» اکنون به صفحه داخلی افزونه هدایت می‌کند.
- صفحه‌های مستقل افزونه‌ها وجود دارند؛ بعداً می‌توانید آن‌ها را با تصاویر واقعی، آموزش استفاده، FAQ و مستندات تکمیل کنید.
- برای نصب وردپرس، تنها فایل ZIP واقعی همان افزونه را در `assets/downloads/` آپلود کنید. بدون فایل، لینک دانلود فعال نکنید.
- فایل‌های گالری را در `assets/gallery/plugins/` قرار دهید.

## فرم مشاوره

فرم موجود از FormSubmit برای ارسال به ایمیل `tahamahmoodikhorsand@gmail.com` استفاده می‌کند. این ارسال سمت سرویس ثالث انجام می‌شود و برای درخواست نخست ممکن است تأیید آدرس ایمیل از طرف مالک لازم باشد. در محیط محلی یا شبکه‌ای که به FormSubmit دسترسی ندارد، ارسال موفق نخواهد بود. بعد از انتشار وب‌سایت، با یک درخواست واقعی و تأیید ایمیل دریافت موفق را آزمایش کنید.

**وضعیت:** طراحی و تنظیم فرم انجام شده است، اما ارسال ایمیل واقعی و دریافت آن در صندوق ورودی تأیید نشده است.

## نسخه ۲٫۲ — گالری پروژه‌ها

- پاپ‌آپ پروژه‌ها اکنون بخش‌های اختیاری دارد: `gallery`، `before`/`after` (آرایه)، `seo`، `speed` و `instagram` در `projectDetails`. بخشی که کلیدش وجود داشته باشد ولی خالی باشد، جایگاه تصویر نشان می‌دهد؛ با `"noGallery": true` بخش گالری مخفی می‌شود.
